# Bonus

#### What is WordPress?
**WordPress** is a Content Management System (CMS), powering over 40% of all websites on the internet. It allows users to build, design, and manage websites without writing code from scratch. it contains customizable templates to be edited by the user. 
---

## Key Features

1. **User-Friendly Dashboard**
2. **Millions of Themes & Visual Customization**
3. **Plugins & Extensibility**
   With over 55,000+ plugins, developers can add features like SEO optimization, contact forms, security layers, and online stores with minimal effort.
4. **SEO Friendly**
   Out-of-the-box clean URL structures, meta tags, and integration with top SEO plugins make ranking on search engines easier.
5. **Open Source & Large Community**
